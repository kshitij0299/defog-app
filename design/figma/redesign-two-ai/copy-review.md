# UI copy review

Read the new labels against the project-local Unslop core contract. Concrete defect: “Your task hasn’t been saved” was inaccurate when canceling changes to an existing task. Changed to “Your changes haven’t been saved,” with “Keep editing?” and “Discard changes.” This preserves the action and removes ambiguity.

The phrase scanner found no hard or soft matches. Short labels, schedule names and recovery instructions are literal UI text and were protected. No conversational hero text was added. Prototype limitations remain outside product UI.
